### About Me

Full-Stack Developer and student at the **University of Pécs, Faculty of Engineering and Information Technology**, with hands-on experience delivering web applications across the entire stack, from database design and REST APIs to interactive, type-safe user interfaces.

**Experience**

- **Backend development:** Designed and implemented RESTful APIs in **Java and Spring Boot**, including relational data modelling with JPA and input validation.
- **Team-based product development:** Contributed to a university platform built with **Laravel, Vue 3, Inertia.js and MySQL** in a three-person agile team, taking responsibility for project architecture, database schema design and development workflow.
- **Thesis project:** Developing an interactive web application with real-time **3D visualization** using **TypeScript, SvelteKit and Three.js**.

**Focus**

Building on a solid foundation in software engineering, I am expanding into **Data Analysis and Data Science** with Python and SQL. My goal is to combine analytical skills with full-stack development to deliver data-driven applications that support informed decision-making.
